Movie Reservation System project from [roadmap.sh](https://roadmap.sh/projects/movie-reservation-system) Backend Developer Roadmap. 

## 📝 About the Project

A backend system for a movie reservation service. The service will allow users to sign up, log in, browse movies, reserve seats for specific showtimes, and manage their reservations. The system also features user authentication, movie and showtime management, seat reservation functionality, and reporting on reservations.
